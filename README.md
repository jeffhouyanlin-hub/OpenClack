# OpenClack

Silent installer GUI for OpenClaw.

## Tech Stack

- Electron
- TypeScript
- React
- Vite
- electron-builder

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build
npm run build

# Package for distribution
npm run package
```
